# @framework/support

Laravel-style helpers (config, env, abort, logger, retry, and execution context accessors).

> **Read-only subtree split** — This package is developed inside the main [**mohamedhabibwork/framework**](https://github.com/mohamedhabibwork/framework/tree/main/packages/support) monorepo and automatically synced to [`mohamedhabibwork/framework-support`](https://github.com/mohamedhabibwork/framework-support). Please open issues and pull requests in the main framework repository.

## Installation

### Inside a Standalone App (via GitHub)

```json
{
  "dependencies": {
    "@framework/support": "github:mohamedhabibwork/framework-support"
  }
}
```

```sh
bun install
```

### Creating a New Application

Use the starter application template repository to bootstrap a full application with all framework packages pre-wired:

```sh
gh repo create my-api --template mohamedhabibwork/framework-app --clone
cd my-api
bun install
```
